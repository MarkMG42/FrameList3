# FrameDrawingPackage P2.3 — состояния отображения и компоновка

Один новый чертёж: **один общий лист + три листа на каждую выбранную раму**. Для трёх рам — 10 листов. Самостоятельный FrameAutoSize в корне репозитория не меняется.

## Как определяется состав

P2.3 работает со **состояниями отображения текущей конфигурации сборки**. Конфигурации больше не перебираются.

При запуске укажите:

1. Номер состояния для общего вида всей сборки. Обычно это «По умолчанию». Первый лист показывает только изометрию, без простановки размеров.
2. Номера состояний отдельных рам, например `2,3,4`. `*` выбирает все состояния, кроме общего. Имена с «рама»/«frame» предлагаются в поле ввода автоматически.

В каждом выбранном состоянии должна быть видна **ровно одна отдельная деталь рамы .sldprt**, а также нужные уголки, ножки, пластины и прочее оснащение. Другие рамы должны быть скрыты. Макрос проверяет видимость компонента и его родителей, подавление, загрузку и имя файла (`рама`/`frame`). Если видимых деталей рам несколько или ни одной, создание комплекта останавливается с объяснением.

Состояние отображения явно закрепляется за каждым сборочным чертёжным видом через `IView.DisplayState`. Простое переключение сборки после создания чертежа не должно менять состав этих видов. Состояния не создаются и не редактируются. Разбиение тел одной многотельной детали на разные рамы этим механизмом не выполняется.

## Листы

| Лист | Содержание |
|---|---|
| Общий_вид, один раз | Вся сборка в выбранном общем состоянии, изометрия, без размеров |
| F001_…_Общий | Изометрия отдельной рамы с её оснащением; длины только тел детали рамы, FrameCutListDimensionsV3 |
| F001_…_Сверловка | Именно SLDPRT рамы в конфигурации её экземпляра; InsertWeldWithHoles |
| F001_…_Монтаж | Сборка в состоянии данной рамы, спереди и сверху; FrameAutoSize |

Далее та же тройка для F002, F003 и т. д. Имя состояния не определяет имя файла детали: файл берётся из единственного видимого подходящего компонента.

## Масштабы и рамки

- На листе **сверловки** масштаб листа — **1:10**. Исходная изометрия детали также устанавливается **1:10**, вместо прежнего уменьшения до маленького прямоугольника. Масштаб вынесенных деталей сохранён: DETAIL_SCALE = 0.2, то есть 1:5. **Разрыв запрашивается для длины более 900 мм** вместо 1200 мм. Поиск свободного от отверстий участка, сохранение фактической длины размера и проверки разрыва сохранены; если безопасного участка нет, выводится предупреждение. Раскладка сверловочных видов восстановлена из приложенного рабочего файла: первый слева, остальные справа. Большое число деталей может потребовать большего формата.
- На изометрии с длинами масштаб повторно подбирается **после создания размеров**, с учётом положения надписей. Проверяются истинные значения и привязки размеров при изменении масштаба. Подбирается непрерывный масштаб по доступной области, без округления к стандартному ряду 1:5/1:10.
- На **монтажном** листе предварительно строится план размеров без их создания. По габаритам видов и месту для размерных линий сравниваются два размещения: рядом и друг над другом. Выбирается более крупный одинаковый масштаб обоих видов. Затем размеры создаются и проверяется размещение по фактическим положениям их аннотаций.
- Оба монтажных вида получают режим **«Невидимые линии отображаются»**, касательные кромки — **скрыты**. Над видами создаются подписи **«Вид спереди»** и **«Вид сверху»**, 3,5 мм, с проверкой попадания внутрь рамки.
- Текст монтажных размеров — **3,5 мм**. Он не уменьшается вместе с моделью. Для надписей предусмотрены консервативные припуски; это не точное измерение контуров шрифта и не математический поиск глобального оптимума.
- Для монтажного листа рабочая область: от 25 мм слева, 10 мм справа, 15 мм сверху и 45 мм снизу. Это учитывает типовую рамку с полем слева 20 мм и оставляет низ под основную надпись. Необычная рамка/штамп требуют изменения полей в FramePackageSupport.
- Сверху сохраняются размеры X снизу и Y слева; спереди — возле соответствующих стоек. Одинаковые высоты разных стоек не объединяются.
- В новом чертеже скрываются вспомогательные оси, временные оси, плоскости, начала координат и эскизы. Это убирает вспомогательную графику, которая может выглядеть как полоски/кресты рядом с видами. Настройки исходных моделей не меняются. Если полоски останутся, потребуется проверить их тип в SolidWorks.

## Обновление P2.1/P2.2 до P2.3

Сохраните локальные пути DRAWING_TEMPLATE (FrameDrawingPackage) и TABLE_TEMPLATE (InsertWeldWithHoles), если вы их задавали. Замените **три модуля**:

- FrameDrawingPackage
- InsertWeldWithHoles
- FrameAutoSize

FramePackageSupport и FrameCutListDimensionsV3 по сравнению с P2.2 не менялись. Сначала удалите старые одноимённые модули, затем импортируйте BAS. Верните свои локальные пути, выполните **Debug → Compile VBAProject**, сохраните SWP. Команда запуска из сборки — **FrameDrawingPackage.main**.

Если устанавливаете комплект поверх версии старее P2.1, импортируйте все пять модулей: в P2.1 были изменены поддержка изометрии и подписи видов.

## Установка с нуля

Создайте отдельную копию рабочего SWP. Импортируйте все пять BAS из архива. Удалите старые одноимённые модули, но не ThisLibrary/SOLIDWORKS Objects. В Tools → References должны быть включены SolidWorks и SolidWorks Constants. Затем Debug → Compile и сохранение SWP.

BAS имеют кодировку CP1251 и CRLF, TXT — UTF-8 копии для чтения. Импортировать нужно BAS. Нативный SWP здесь не пересобирался: сохраните его редактором SolidWorks.

## Шаблоны

В FrameDrawingPackage:

```vba
Private Const DRAWING_TEMPLATE As String = ""
```

Можно вписать полный путь к `.drwdot`. Пустое значение использует шаблон чертежа по умолчанию SolidWorks; если он не найден, макрос запросит путь. Шаблон должен иметь один исходный лист, формат A3 альбомный или больше.

В InsertWeldWithHoles константа TABLE_TEMPLATE пуста. При необходимости задайте путь к своему `.sldwldtbt` локально. Поиск стандартного установленного шаблона сохранён; внутренние сетевые пути в комплект не включаются.

## Список вырезов и позиции на сверловке

По приложенному рабочему InsertWeldWithHoles.bas таблица создаётся внутри листа и затем переносится **за правый край**, в рабочую область чертежа. Она остаётся связанной с моделью и используется для сортировки, нумерации и позиций. В рамку печатного листа таблица при таком варианте не входит — это поведение присланного файла.

Проверка P2.1, требовавшая вместить всю таблицу в рамку, удалена. Именно её отказ на большой таблице вызывал остановку и откат с удалением таблицы и новых видов. Процедуры вставки/выноса таблицы и раскладки сверловочных видов в P2.2 дословно сопоставлены с присланным модулем. Если тел со сверловкой нет, созданная корректная таблица сохраняется. Откат при реальной ошибке геометрии или повреждённой вставке сохранён, как в исходном модуле.

Поиск шаблона: локальная TABLE_TEMPLATE, папки списка вырезов из настроек SolidWorks, стандартные языковые папки установки. Если доступный шаблон не найден, макрос попросит полный путь к `.sldwldtbt`. Внутренние сетевые пути не включены в исходники; указывайте их только локально.

Сохранены умная сортировка профилей/длин, согласование строк с вынесенными деталями, связанные позиции с количеством на вынесенных видах и выноски на исходной изометрии. Позиции используют реальные номера списка вырезов, а не вписанные вручную числа. Если сортировка, нумерация или привязки не подтверждены, макрос сообщает об этом. Порог безопасного разрыва остаётся **более 900 мм**.

## Сохранение и сообщения

Чертёж и исходные модели автоматически не сохраняются. Журналы и служебные файлы при запуске не создаются; сообщения о ходе работы идут в Immediate (Ctrl+G).

После выполнения или ошибки восстанавливаются исходные конфигурации деталей и сборки, исходное состояние отображения сборки. Затем проверяются привязки и значения размеров и закреплённые состояния сборочных видов. Если всё завершено без предупреждений — только **«выполнено успешно»**. Иначе показываются этап и причина. Частично созданный чертёж остаётся открытым для проверки.

## Первая проверка в SolidWorks

Начните с общего состояния и одного состояния отдельной рамы: должно получиться четыре листа. На первом нет размеров; на втором видна одна рама с её оснащением и длинами; на третьем исходная деталь и масштаб листа/исходного вида 1:10; на четвёртом — два крупных вида с монтажными размерами в пределах рамки. Проверьте отсутствие вспомогательных крестов и восстановление исходного состояния сборки. Затем выберите все три состояния: ожидается 10 листов одного чертежа.

Исходники проверяются грамматикой VBA 7.1, контрактами межмодульных вызовов и наличием методов/свойств по interop SolidWorks. Это **статические проверки**, не компиляция редактором VBE и не исполнение в SolidWorks. Ограничения геометрического распознавания исходных макросов сохраняются.

## Дополнительные размеры до труб с прорезями

На виде сверху добавлены вертикальные размеры **от общей нижней базы до верхней кромки горизонтальных труб с продолговатыми прорезями**. Для показанных двух труб ожидаются два дополнительных размера. Остальные размеры сохраняются; размеры ставятся слева.

Новое правило применяется только к горизонтальным трубам (по прежнему распознаванию профиля и оси). Проверяется геометрия внутренних контуров на плоских гранях, параллельных виду: две одинаковые полукруглые оконечности и параллельные прямые стороны. Поддерживается разбиение сторон/дуг на несколько рёбер. Обычные круглые отверстия и прямоугольные контуры с четырьмя скруглёнными углами не считаются такими прорезями. Трубы без прорезей не получают новых размеров по этому правилу. Исходное правило размеров до швеллеров сохранено.

Новые размеры включены в предварительный расчёт монтажной компоновки: место для двух добавленных размерных линий учитывается при подборе масштаба. Расчётный признак тела выводится в Immediate как TOP SLOT с capsule=True/False. Это геометрическое распознавание капсульных прорезей; произвольные фасонные или сплайновые вырезы автоматически не распознаются.

Численная часть проверки формы контура проверена на 12 примерах через перевод извлечённого расчёта VBA в Python: обычная/повёрнутая прорезь, разбиение прямых рёбер, непрямоугольная ориентация в модели и случаи, которые нужно отклонить. Чтение топологии SolidWorks этим тестом не выполняется.

## Проверка разрыва P2.3

В присланном журнале один отменённый разрыв: DRILL_F002_Рама №2_Сверловка_002. Старая проверка обнаружила изменение числа видимых круговых рёбер. По этому фрагменту нельзя определить, исчезло ли отверстие или изменилось число рёбер одного отверстия, возвращаемых SolidWorks.

P2.3 сохраняет исходный поиск безопасного участка и отмену неудачного разрыва. Вместо сравнения количества рёбер сопоставляются уникальные оси отверстий и их диаметры в координатах модели. Две полные окружности на противоположных стенках трубы, принадлежащие одной оси и одному диаметру, учитываются как одна проекция отверстия. Частичные дуги не добавляются: условие полной окружности сохранено.

После разрыва требуются одинаковые наборы таких отверстий с взаимно однозначным соответствием. Потеря отверстия, смена диаметра/оси и неоднозначное соответствие вызывают прежний откат. Значения всех созданных размеров также проверяются. В Immediate печатаются число круговых рёбер до/после и число уникальных осей/диаметров; при несовпадении указываются данные несопоставленного отверстия. Файловые журналы не добавлены.

Для проверки перезапустите комплект на раме №2 и проверьте второй сверловочный вид. Если причина была в дублирующих круговых рёбрах, разрыв должен сохраниться. Если реально меняется состав отверстий, разрыв будет отменён, а новый вывод Immediate позволит уточнить причину. Порог длины остаётся более 900 мм.

Вспомогательная арифметика сравнения осей проверена на девяти примерах через перевод извлечённого из VBA расчёта в Python (противоположные нормали/стенки, наклонные оси, смещения и диаметры). Это не нативное исполнение VBA. Нативного запуска P2.3 в SolidWorks здесь не было. Размещение таблицы за правой границей, сверловочные размеры/позиции, подбор масштаба изометрии и прежние монтажные размеры сохранены. На виде сверху добавлены указанные выше размеры до труб с прорезями.
