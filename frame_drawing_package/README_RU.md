# FrameDrawingPackage P2 — состояния отображения и компоновка

Один новый чертёж: **один общий лист + три листа на каждую выбранную раму**. Для трёх рам — 10 листов. Самостоятельный FrameAutoSize в корне репозитория не меняется.

## Как определяется состав

P2 работает со **состояниями отображения текущей конфигурации сборки**. Конфигурации больше не перебираются.

При запуске укажите:

1. Номер состояния для общего вида всей сборки. Обычно это «По умолчанию». Первый лист показывает только изометрию, без простановки размеров.
2. Номера состояний отдельных рам, например `2,3,4`. `*` выбирает все состояния, кроме общего. Имена с «рама»/«frame» предлагаются в поле ввода автоматически.

В каждом выбранном состоянии должна быть видна **ровно одна отдельная деталь рамы .sldprt**, а также нужные уголки, ножки, пластины и прочее оснащение. Другие рамы должны быть скрыты. Макрос проверяет видимость компонента и его родителей, подавление, загрузку и имя файла (`рама`/`frame`). Если видимых деталей рам несколько или ни одной, создание комплекта останавливается с объяснением.

Состояние отображения явно закрепляется за каждым сборочным чертёжным видом через `IView.DisplayState`. Простое переключение сборки после создания чертежа не должно менять состав этих видов. Состояния не создаются и не редактируются. Разбиение тел одной многотельной детали на разные рамы этим механизмом не выполняется.

## Листы

| Лист | Содержание |
|---|---|
| Общий_вид, один раз | Вся сборка в выбранном общем состоянии, изометрия, без размеров |
| F001_…_Общий | Изометрия отдельной рамы с её оснащением; длины только тел детали рамы, FrameCutListDimensionsV3 |
| F001_…_Сверловка | Именно SLDPRT рамы в конфигурации её экземпляра; InsertWeldWithHoles |
| F001_…_Монтаж | Сборка в состоянии данной рамы, спереди и сверху; FrameAutoSize |

Далее та же тройка для F002, F003 и т. д. Имя состояния не определяет имя файла детали: файл берётся из единственного видимого подходящего компонента.

## Масштабы и рамки

- На листе **сверловки** масштаб листа — **1:10**. Исходная изометрия детали также устанавливается **1:10**, вместо прежнего уменьшения до маленького прямоугольника. Масштаб вынесенных видов деталей, разрывы, сверловочные размеры и правила их раскладки исходного InsertWeldWithHoles сохранены (DETAIL_SCALE = 0.2, то есть 1:5). Большое число деталей может потребовать большего формата.
- На **монтажном** листе предварительно строится план размеров без их создания. По габаритам видов и месту для размерных линий сравниваются два размещения: рядом и друг над другом. Выбирается более крупный одинаковый масштаб обоих видов. Затем размеры создаются и проверяется размещение по фактическим положениям их аннотаций.
- Текст монтажных размеров — **3,5 мм**. Он не уменьшается вместе с моделью. Для надписей предусмотрены консервативные припуски; это не точное измерение контуров шрифта и не математический поиск глобального оптимума.
- Для монтажного листа рабочая область: от 25 мм слева, 10 мм справа, 15 мм сверху и 45 мм снизу. Это учитывает типовую рамку с полем слева 20 мм и оставляет низ под основную надпись. Необычная рамка/штамп требуют изменения полей в FramePackageSupport.
- Сверху сохраняются размеры X снизу и Y слева; спереди — возле соответствующих стоек. Одинаковые высоты разных стоек не объединяются.
- В новом чертеже скрываются вспомогательные оси, временные оси, плоскости, начала координат и эскизы. Это убирает вспомогательную графику, которая может выглядеть как полоски/кресты рядом с видами. Настройки исходных моделей не меняются. Если полоски останутся, потребуется проверить их тип в SolidWorks.

## Обновление P1/P1.1

Сохраните локально заданный путь `DRAWING_TEMPLATE`, если он был вписан. Замените **три модуля**:

- FrameDrawingPackage
- FramePackageSupport
- FrameAutoSize

FrameCutListDimensionsV3 и InsertWeldWithHoles по сравнению с P1.1 не менялись. Их можно оставить, в том числе сохранить свой путь TABLE_TEMPLATE. Новые модули не должны получить имена с добавленным `1`: сначала удалите старые одноимённые, затем импортируйте BAS. Выполните **Debug → Compile VBAProject**, сохраните SWP. Команда запуска из сборки — **FrameDrawingPackage.main**.

## Установка с нуля

Создайте отдельную копию рабочего SWP. Импортируйте все пять BAS из архива. Удалите старые одноимённые модули, но не ThisLibrary/SOLIDWORKS Objects. В Tools → References должны быть включены SolidWorks и SolidWorks Constants. Затем Debug → Compile и сохранение SWP.

BAS имеют кодировку CP1251 и CRLF, TXT — UTF-8 копии для чтения. Импортировать нужно BAS. Нативный SWP здесь не пересобирался: сохраните его редактором SolidWorks.

## Шаблоны

В FrameDrawingPackage:

```vba
Private Const DRAWING_TEMPLATE As String = ""
```

Можно вписать полный путь к `.drwdot`. Пустое значение использует шаблон чертежа по умолчанию SolidWorks; если он не найден, макрос запросит путь. Шаблон должен иметь один исходный лист, формат A3 альбомный или больше.

В InsertWeldWithHoles константа TABLE_TEMPLATE пуста. При необходимости задайте путь к своему `.sldwldtbt` локально. Поиск стандартного установленного шаблона сохранён; внутренние сетевые пути в комплект не включаются.

## Сохранение и сообщения

Чертёж и исходные модели автоматически не сохраняются. Журналы и служебные файлы при запуске не создаются; сообщения о ходе работы идут в Immediate (Ctrl+G).

После выполнения или ошибки восстанавливаются исходные конфигурации деталей и сборки, исходное состояние отображения сборки. Затем проверяются привязки и значения размеров и закреплённые состояния сборочных видов. Если всё завершено без предупреждений — только **«выполнено успешно»**. Иначе показываются этап и причина. Частично созданный чертёж остаётся открытым для проверки.

## Первая проверка в SolidWorks

Начните с общего состояния и одного состояния отдельной рамы: должно получиться четыре листа. На первом нет размеров; на втором видна одна рама с её оснащением и длинами; на третьем исходная деталь и масштаб листа/исходного вида 1:10; на четвёртом — два крупных вида с монтажными размерами в пределах рамки. Проверьте отсутствие вспомогательных крестов и восстановление исходного состояния сборки. Затем выберите все три состояния: ожидается 10 листов одного чертежа.

Исходники проверяются грамматикой VBA 7.1, контрактами межмодульных вызовов и наличием методов/свойств по interop SolidWorks. Это **статические проверки**, не компиляция редактором VBE и не исполнение в SolidWorks. Ограничения геометрического распознавания исходных макросов сохраняются.
