# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2.4

[Скачать FrameDrawingPackage P2.4](frame_drawing_package/FrameDrawingPackage_P2_4.zip) · [Инструкция](frame_drawing_package/README_RU.md)

Один общий лист без размеров и по три листа на каждую раму из выбранных состояний отображения: изометрия с длинами, сверловка детали, монтажные размеры. Размеры до горизонтальных труб с капсульными прорезями сохранены из P2.3.

P2.4 исправляет оставшуюся проверку числа рёбер после перемещения сверловочного вида: на обоих этапах сравниваются оси/диаметры отверстий. Поиск безопасного участка и порог более 900 мм сохранены.

Для повторного применения разрыва откройте готовый чертёж, выберите рамку одного сверловочного вида DRILL_... и запустите ту же FrameDrawingPackage.main. Повторно создаются только линии разрыва выбранного вида; таблица, остальные виды и размеры не пересоздаются. Проверяются исходные значения и привязки размеров, отверстия и результат после обновления. При отказе новый разрыв отменяется; окно сообщения содержит вид, длину, масштаб, угол и причину. Текст можно скопировать Ctrl+C. Запуск из сборки создаёт комплект как раньше.

При обновлении P2.3 замените только FrameDrawingPackage и InsertWeldWithHoles. Сохраните и верните свои DRAWING_TEMPLATE и TABLE_TEMPLATE; Debug → Compile, сохранение SWP. Журналы/служебные файлы при запуске не создаются.

Статические проверки прошли. Нативного запуска P2.4 в SolidWorks здесь не было; причина отсутствия разрыва на скриншоте ещё не подтверждена. Новый режим позволяет проверить конкретный готовый вид без пересоздания комплекта.
