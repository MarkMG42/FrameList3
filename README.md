# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2

[Скачать FrameDrawingPackage P2](frame_drawing_package/FrameDrawingPackage_P2.zip) · [Инструкция по установке](frame_drawing_package/README_RU.md)

Один общий лист с изометрией всей сборки без размеров, затем по три листа на каждую раму из выбранных состояний отображения текущей конфигурации: изометрия рамы с длинами, сверловка детали, монтажные виды с размерами. Для трёх рам — 10 листов. В каждом состоянии должна быть видна одна отдельная деталь рамы с её оснащением. Состояние закрепляется за сборочными видами.

На сверловке масштаб листа и исходной изометрии 1:10; масштаб вынесенных деталей сохранён. Монтажные виды компонуются с учётом размерных линий, текст 3,5 мм; сравниваются размещения рядом и друг над другом. Вспомогательные оси, плоскости, начала координат и эскизы в новом чертеже скрываются.

При обновлении P1/P1.1 замените три модуля: FrameDrawingPackage, FramePackageSupport и FrameAutoSize. Сохраните локальный DRAWING_TEMPLATE. FrameCutListDimensionsV3 и InsertWeldWithHoles не менялись. Затем Debug → Compile и сохранение SWP; запуск FrameDrawingPackage.main из сборки. Журналы/служебные файлы при запуске не создаются. Статические проверки пройдены; изменения P2 ещё не исполнены в SolidWorks.
