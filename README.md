# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2.3

[Скачать FrameDrawingPackage P2.3](frame_drawing_package/FrameDrawingPackage_P2_3.zip) · [Инструкция](frame_drawing_package/README_RU.md)

Один общий лист без размеров и по три листа на каждую раму из выбранных состояний отображения: изометрия с длинами, сверловка детали, монтажные размеры.

В P2.3 на виде сверху добавлены размеры от общей нижней базы до верхних кромок горизонтальных труб с капсульными прорезями. Существующие размеры сохранены; трубы только с круглыми отверстиями не получают новых размеров по этому правилу. Поиск прорезей использует внутренние контуры на плоских гранях; новое место под размерные линии учитывается при компоновке.

Проверка разрыва теперь сопоставляет уникальные оси отверстий и диаметры в координатах модели. Изменение числа круговых рёбер одного отверстия само по себе не отменяет разрыв. Потеря отверстия, смена его диаметра/оси или неоднозначное соответствие по-прежнему вызывают откат; поиск безопасного участка и проверка значений размеров сохранены. В Immediate выводятся числа рёбер и уникальных отверстий до/после.

Порог безопасного разрыва более 900 мм. Таблица списка вырезов остаётся за правым краем листа по присланному рабочему модулю. Подбор масштаба изометрии и режимы/подписи монтажных видов сохранены.

При обновлении P2.2 замените FrameDrawingPackage, InsertWeldWithHoles и FrameAutoSize. Сохраните и верните локальные DRAWING_TEMPLATE и TABLE_TEMPLATE. Затем Debug → Compile, сохранение SWP и запуск FrameDrawingPackage.main. Журналы/служебные файлы не создаются. Грамматика и контракты исходников проверены; арифметические части сравнения осей и распознавания капсулы проверены на 9 и 12 примерах через перевод извлечённого расчёта VBA в Python. P2.3 ещё не исполнен в SolidWorks.

[Предыдущий комплект P2.2](frame_drawing_package/FrameDrawingPackage_P2_2.zip).
