# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2.5

[Скачать FrameDrawingPackage P2.5](frame_drawing_package/FrameDrawingPackage_P2_5.zip) · [Инструкция](frame_drawing_package/README_RU.md)

Один общий лист без размеров и по три листа на каждую раму из выбранных состояний отображения: изометрия с длинами, сверловка детали, монтажные размеры. Размеры до горизонтальных труб с капсульными прорезями сохранены.

P2.5 сохраняет прежний способ координат первой попыткой. После неудачи и проверенного отката пробуются прямые координаты проекции и отсчёт относительно проекции начала модели. Отступы GetOutline учитываются отдельно. Перед повторной попыткой восстанавливается положение, перечитывается геометрия и проверяются отверстия, габарит и размеры.

Разрыв принимается только при сохранении осей/диаметров отверстий, значений размеров и сокращении вида до 150 мм на листе. Потеря отверстия продолжает отменять разрыв. Максимум три попытки; при общем отказе сообщение содержит причины каждой и использованные начала отсчёта/API-координаты.

Для проверки готового вида выделите рамку нужного DRILL_... на чертеже и запустите FrameDrawingPackage.main. Таблица, остальные виды и размеры не пересоздаются. При успехе — «выполнено успешно»; текст окна отказа можно скопировать Ctrl+C. Запуск из сборки создаёт комплект как раньше.

При обновлении P2.4 замените только FrameDrawingPackage и InsertWeldWithHoles. Сохраните и верните локальные DRAWING_TEMPLATE и TABLE_TEMPLATE, выполните Debug → Compile и сохраните SWP. Журналы/служебные файлы при запуске не создаются.

Статические проверки и девять расчётных примеров планирования/координат прошли. Примеры включают деталь 1102 мм с отверстиями 30/120 мм и смещение начала отсчёта, способное скрыть только второе отверстие. Это перевод арифметики VBA в Python, а не исполнение SolidWorks API. Нативного запуска P2.5 здесь не было; фактическое смещение в пользовательском виде ещё не подтверждено.
