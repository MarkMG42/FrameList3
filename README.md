# FrameList3 — FrameAutoSize R1.4

VBA-макрос монтажных размеров рамы на видах спереди и сверху в чертеже SolidWorks.

**Первый кандидат: статические проверки пройдены, в SolidWorks ещё не запускался.**

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_4.zip)
- [Инструкция по установке и правила размеров](README_RU.md)
- [BAS для импорта в VBA](FrameAutoSize.bas) — CP1251/CRLF
- [TXT для копирования](FrameAutoSize.txt) — UTF-8
- [Результаты проверок](validation.json)

Сначала импортируйте модуль в новый SWP и выполните **Debug → Compile**. Затем выберите вид спереди и запустите `DiagnoseFront`, выберите вид сверху и запустите `DiagnoseTop`. Журналы сохраняются рядом с запущенным `.swp`. Пришлите два TXT-журнала; диагностика не создаёт размеры.

Для простановки предназначены `Front`, `Top` и `main`. Повторный запуск добавляет размеры повторно. Основная рама ищется по имени файла `рама`/`frame`; добавленные компоненты сборки не образмеряются.

В R1.1 изменена папка журнала: TEMP больше не используется. Если папка макроса недоступна для записи, можно указать другую существующую папку. По журналам R1.1 обнаружено вырожденное преобразование координат; в R1.2 исправлен формат массива CreatePoint. [Предыдущий комплект R1](FrameAutoSize_R1.zip) сохранён.


R1.2 исправляет передачу координат в `CreatePoint`: используется массив Double, добавлена проверка преобразования и защита от нулевого направления экстремума. Причина отказа R1.1 установлена по двум журналам; повторная диагностика в SolidWorks ещё требуется. [Предыдущий комплект R1.1](FrameAutoSize_R1_1.zip) сохранён.


R1.3: сверху учитываются трубы/швеллеры и торцы стоек, уголки исключены. По согласованному примеру ожидаются X 355/600/640/1220 и Y 235/350/370 мм. Размерные линии при нехватке места переносятся на другую сторону. Диагностика R1.2 спереди прошла; создание размеров R1.3 ещё требует нативной проверки. [Предыдущий комплект R1.2](FrameAutoSize_R1_2.zip) сохранён.


R1.4 добавляет `DiagnoseContext`: PID SolidWorks, список открытых документов и активный документ до/после открытия журнала. При отказе ActiveDoc запустите эту команду и пришлите TXT. Документы не переключаются и не изменяются; причина ActiveDoc=Nothing пока не установлена. [Предыдущий комплект R1.3](FrameAutoSize_R1_3.zip) сохранён.
