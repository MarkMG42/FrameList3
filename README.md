# FrameList3 — FrameAutoSize R1.7

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_7.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, выполните Debug → Compile и сохраните SWP. Тогда в списке Macros останется только `FrameList3.FrameAutoSize.main`.

Выберите один вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

R1.6 подтверждена пользователем. В R1.7 изменены только видимость вспомогательных команд и номер версии; геометрическая логика сохранена. [Рабочий комплект R1.6](FrameAutoSize_R1_6.zip) и прочая история сохранены.
