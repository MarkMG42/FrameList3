# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2.2

[Скачать FrameDrawingPackage P2.2](frame_drawing_package/FrameDrawingPackage_P2_2.zip) · [Инструкция](frame_drawing_package/README_RU.md)

Один общий лист без размеров и по три листа на каждую раму из выбранных состояний отображения: изометрия с длинами, сверловка детали, монтажные размеры.

P2.2 восстанавливает вставку и размещение таблицы по присланному рабочему InsertWeldWithHoles.bas: таблица переносится за правый край листа и используется для сортировки и связанных позиций. Убрана добавленная в P2.1 проверка, останавливавшая комплект на большой таблице и запускавшая откат. Процедуры вставки таблицы и раскладки сверловочных видов сопоставлены с приложенным исходником.

Порог безопасного разрыва более 900 мм, подбор масштаба изометрии с размерами, подписи и режимы монтажных видов сохранены. Масштаб листа и исходной изометрии сверловки 1:10.

При обновлении P2.1 замените только FrameDrawingPackage и InsertWeldWithHoles. Сохраните и верните свои локальные DRAWING_TEMPLATE и TABLE_TEMPLATE. Затем Debug → Compile, сохранение SWP и запуск FrameDrawingPackage.main. При установке поверх более старых версий импортируйте все пять модулей. Журналы/служебные файлы не создаются. Статические проверки пройдены; P2.2 ещё не исполнен в SolidWorks.

[Предыдущий комплект P2.1](frame_drawing_package/FrameDrawingPackage_P2_1.zip).
