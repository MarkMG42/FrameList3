# FrameList3 — FrameAutoSize R1.8

Размеры рамы на видах спереди и сверху в SolidWorks. Единственная команда запуска — **`FrameAutoSize.main`**.

- [Скачать комплект ZIP](https://github.com/MarkMG42/FrameList3/raw/refs/heads/main/FrameAutoSize_R1_8.zip)
- [Инструкция](README_RU.md)
- [Модуль BAS для импорта](FrameAutoSize.bas)
- [Исходник TXT](FrameAutoSize.txt)
- [Проверки](validation.json)

Замените модуль `FrameAutoSize`, удалите из своего SWP пустой шаблон **`FrameList31`**, если он остался, выполните Debug → Compile и сохраните SWP.

Выберите вид спереди или сверху и запустите `main`. После полной простановки и проверки — **«выполнено успешно»**. Сверху все X снизу, все Y слева. Спереди размеры располагаются возле своих стоек; одинаковые высоты у разных стоек не объединяются.

**R1.8 не создаёт журналы или другие служебные файлы при запуске.** Ошибки показываются в окне сообщения; подробности доступны в Immediate редактора VBA (Ctrl+G). Файловое логирование удалено полностью.

Расчёты и размещение сохранены. [Предыдущий комплект R1.7](FrameAutoSize_R1_7.zip), подтверждённая R1.6 и прочая история сохранены.

## Комплект чертежей из сборки — P2.1

[Скачать FrameDrawingPackage P2.1](frame_drawing_package/FrameDrawingPackage_P2_1.zip) · [Инструкция](frame_drawing_package/README_RU.md)

Один общий лист без размеров, затем по три листа на каждую раму из выбранных состояний отображения: изометрия с длинами, сверловка детали, монтажные размеры. В каждом состоянии должна быть видна одна отдельная деталь рамы с её оснащением.

P2.1 подбирает масштаб изометрии после простановки длин с учётом надписей. На сверловке список вырезов обязателен и размещается внутри листа, справа над основной надписью; сохранены сортировка и связанные позиции. При отсутствии шаблона предлагается указать .sldwldtbt. Порог безопасного разрыва снижен до 900 мм. Масштаб листа и исходной изометрии сверловки остаётся 1:10.

Монтажные виды показывают невидимые линии, касательные кромки скрыты. Добавляются подписи «Вид спереди» и «Вид сверху». Компоновка монтажных видов и текст 3,5 мм сохранены.

Для обновления P2 замените четыре модуля: FrameDrawingPackage, FramePackageSupport, FrameCutListDimensionsV3, InsertWeldWithHoles. Сохраните и верните свои локальные DRAWING_TEMPLATE и TABLE_TEMPLATE. FrameAutoSize не менялся. Затем Debug → Compile, сохранение SWP и запуск FrameDrawingPackage.main. Журналы/служебные файлы не создаются. Статические проверки пройдены; P2.1 ещё не исполнен в SolidWorks.
