# FrameAutoSize R1.8

VBA-макрос монтажных размеров рамы на существующих видах спереди и сверху в чертеже SolidWorks.

**R1.6 подтверждена пользователем. В R1.7 оставлена одна публичная команда `FrameAutoSize.main`. В R1.8 полностью удалено создание файлов журналов.** Расчёты, размеры, размещение и проверки сохранены; исходники проверены статически.

## Изменение R1.8

Макрос не создаёт TXT-журналы и другие служебные файлы ни при обычном запуске, ни при ошибках, ни при вызове внутренних диагностических команд. Файловый журнал и выбор папки для него удалены. Подробности направляются только в окно **Immediate** редактора VBA (**Ctrl+G**) через `Debug.Print`. При полном успехе сообщение по-прежнему только **«выполнено успешно»**; при ошибке показываются этап и причина.

Проверено отсутствие операторов файловой записи и сохранение 20 процедур геометрии/создания/проверки размеров без изменений. R1.7 и более ранние архивы сохранены как история. Отдельного нативного запуска R1.8 ещё не было.

## Установка и очистка списка запуска

1. Откройте редактор VBA своего SWP.
2. Замените прежний модуль `FrameAutoSize` файлом `FrameAutoSize.bas` через **File → Import File**. Не оставляйте две копии модуля.
3. В дереве проекта удалите пустой шаблон **`FrameList31`**: правой кнопкой → **Remove FrameList31**. На скриншоте пользователя это второй модуль с автоматически созданным `main`. Он находится внутри пользовательского SWP и не может быть удалён импортом BAS.
4. В проекте должен остаться один модуль **`FrameAutoSize`**. Папку **SOLIDWORKS Objects** не удаляйте.
5. Проверьте ссылки **SolidWorks** и **SolidWorks Constants** в Tools → References, выполните **Debug → Compile VBAProject**, сохраните SWP.

После этого в списке Macros должна остаться одна команда: `FrameList3.FrameAutoSize.main` (имя проекта перед модулем может отличаться).

BAS — CP1251/CRLF с Attribute для импорта. TXT — тот же исходник без Attribute в UTF-8 для копирования. Не импортируйте оба файла. Готовый SWP сохраняется редактором SolidWorks; этот комплект содержит текстовые исходники.

## Запуск

Выделите один вид спереди или сверху и запустите **`FrameAutoSize.main`**. Та же команда подходит для обоих видов; ориентир — стандартное имя ориентации SolidWorks. Если стандартного имени нет, макрос предлагает выбрать «спереди / сверху».

При полном успехе выводится только **«выполнено успешно»**. При ошибках показываются этап и причина. Дополнительные сведения можно скопировать из окна Immediate редактора VBA (Ctrl+G). Файлы журналов не создаются.

Повторный запуск добавляет размеры заново. Прежние размеры автоматически не удаляются. Файлы чертежа и моделей не сохраняются автоматически.

## Правила размеров

Автоматически выбирается одна основная деталь сборки с `рама`/`frame` в имени файла. Для другого имени измените `FRAME_NAME` в начале модуля. Другие компоненты сборки не образмеряются. В самой раме учитываются тела профилей; пластины и прочие тела исключаются. Оси профилей подтверждаются связанным LENGTH и параллельными рёбрами соответствующей длины.

**Спереди:** общая база — верхняя наружная кромка нижнего опорного профиля. Цели — верхние кромки горизонтальных и направленных в глубину профилей. Высоты вертикальных стоек не добавляются. Размеры размещаются возле соответствующих стоек; одинаковые высоты у разных стоек сохраняются отдельно. Для примера получаются 156,5 / 182 / 480 / 480 / 600 / 600 / 901 / 1265 / 1410 мм.

**Сверху:** база — левый нижний угол труб и швеллеров рамы. Уголки исключены. Учитываются поперечные профили и торцы стоек; координаты примыкания к наружной раме пропускаются. До горизонтальных швеллеров, кроме нижнего опорного, добавляются размеры до дальней верхней кромки. Размеры X располагаются только снизу, Y — только слева; меньшие ближе к виду. Для примера X: 355 / 600 / 640 / 1220; Y: 235 / 350 / 370 / 410 / 790 мм. Значения вычисляются из геометрии, не зашиты в код.

`TOP_OVERALL_WIDTH = False` отключает общую ширину рамы сверху. Отступы — 7 мм, шаг линий — 6 мм на бумаге. Если для верхнего вида не хватает места снизу/слева, макрос сообщает об этом до создания размеров. Полного анализа пересечений текстов, соседних видов и штампа нет.

## Проверки и ограничения

Размеры создаются штатными средствами SolidWorks с привязками к реальным рёбрам. Проверяются количество размеров плана, значения сразу и после перестроения, отсутствие dangling. Используется проекционный режим размеров выбранного вида. При ошибке макрос пытается удалить только размеры текущего запуска и восстановить настройки.

Поддерживаются полные ортогональные виды без разрывов, обрезки, разрезов и фильтра отдельных тел. Активные конфигурации моделей должны совпадать с видом и экземпляром; автоматического переключения конфигураций нет. Нестандартные профили, косые элементы, сборочные вырезы и индивидуальные состояния скрытия требуют отдельной проверки. Сопоставление поперечины со стойкой использует проекционное соседство; при отсутствии подходящей стойки используется сам целевой профиль.

Вспомогательные `Front`, `Top` и `Diagnose*` сохранены как Private и не предназначены для обычного выбора в Macros. При необходимости их можно вызвать из редактора VBA. Диагностика не создаёт размеры и файлы; её сообщения остаются подробными, сведения доступны в Immediate.

История и предыдущие рабочие комплекты сохранены в Git и архивах `FrameAutoSize_R1*.zip`, включая подтверждённую R1.6. Пользовательские журналы и пути моделей в репозиторий не публикуются.
