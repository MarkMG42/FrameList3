# Чертёж трубопроводной подсборки

1. Скачайте `PipeDrawing.bas` из этой папки.
2. В SOLIDWORKS выберите **Сервис → Макрос → Создать** и сохраните файл `PipeDrawing.swp`.
3. В редакторе VBA выберите проект нового макроса и выполните **File → Import File…** (`Ctrl+M`). Выберите `PipeDrawing.bas`.
4. Удалите из автоматически созданного модуля пустую процедуру `Sub main()` вместе с `End Sub`, чтобы единственной точкой входа осталась `PipeDrawing.main`.
5. Выполните **Debug → Compile**, сохраните проект (`Ctrl+S`) и закройте редактор.
6. Откройте сохранённую подсборку трубопровода. Выберите **Сервис → Макрос → Выполнить** и укажите `PipeDrawing.swp`. Для кнопки макроса назначьте процедуру `PipeDrawing.main`.

После импорта код хранится внутри `.swp`. При обновлении удалите старый модуль `PipeDrawing` из проекта, импортируйте новую версию и снова сохраните `.swp`.
